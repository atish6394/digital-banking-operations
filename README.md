# digital-banking-operations
A simulated digital banking operations project using Jira to track UPI failures, refund delays, KYC verification delays, and mobile banking login issues through Kanban workflows and dashboards.
Project Overview

This project simulates a digital banking operations workflow using Jira to track and monitor common banking issues.

Issues Tracked

- UPI Payment Failure – Transaction Not Completed
- KYC Verification Delay
- UPI Refund Delay
- Digital Banking Login Failure

Tools Used

- Jira for issue tracking and workflow management
- Kanban Board for monitoring progress
- Jira Dashboard for visualizing issue status and priority
- Saved Filters for tracking issues

Workflow

Idea → To Do → In Progress → In Review → Done

Key Features

- Issue prioritization and assignment
- Start dates and due dates
- Investigation comments and updates
- Dashboard charts and issue summaries

Disclaimer

All cases and data are simulated for learning and portfolio purposes. No real bank systems or customer data are used.
